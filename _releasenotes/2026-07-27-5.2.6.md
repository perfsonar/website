Bug Fixes and Other Changes
----------------------------

### pSConfig
- Fixed parsing issue with quoting in regular expressions

### pScheduler
- Fixed issue with rejecting invalid throughput tests

### Host Metrics
- Update endpoint to use new lookup service. This fixes issue where Toolkit Host Info page would list host as unregistered even if it was.

### LS Registration Daemon
- Quieted logs about bulk refresh messages since are not a real issue preventing registration and just a side effect of the new Lookup Service. 

### PWA
- Updated PWA to use the new lookup service for finding hosts
